# AutoFish Minigame (Fabric 1.21.4)

Клиентский мод: сам забрасывает удочку и проходит мини-игру с полоской (зелёная/жёлтая зона + маркер).

## Сборка без ПК (через GitHub)
1. Создай репозиторий на GitHub, загрузи туда все файлы из этого архива (включая папку `.github`).
2. Вкладка **Actions** → workflow **build** → дождись зелёной галочки.
3. Открой запуск → **Artifacts** → `autofish-jar` → внутри `autofish-1.0.0.jar`.
4. Положи jar в `mods` рядом с Fabric API (0.119.3+1.21.4).

## Управление
- Клавиша **G** или команда `/afish` — вкл/выкл
- `/afish debug` — показывать в чате, что мод видит (зона, маркер)
- `/afish bite` — вытаскивать по обычной поклёвке (если сервер без мини-игры)
- `/afish dump` — сохранить скриншот и вывести цвета в области полоски (для калибровки)

Область полоски и цвета меняются константами в начале `AutoFishClient.java`.
